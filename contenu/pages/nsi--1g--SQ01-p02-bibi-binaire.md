## Une autre façon de dire l'hexadécimal

![Motif de couverture : quatre bits composent un chiffre bibi.](/nsi/1g/assets/bibi-quartets.svg)
:::

::: {.slide .concept}
# Même nombre, autre alphabet

Boby Lapointe a imaginé seize syllabes pour dire les seize chiffres de l'hexadécimal.
Les deux bits de gauche donnent la consonne ; les deux bits de droite, la voyelle.

| Deux bits | `00` | `01` | `10` | `11` |
|:---:|:---:|:---:|:---:|:---:|
| Consonne | H | B | K | D |
| Voyelle | O | A | E | I |

Exemples : `0111` = 7 = **BI** ; `1101` = D = **DA** ; `1111` = F = **DI**.

Chaque groupe de quatre bits reste un chiffre hexadécimal : seule sa prononciation change.
:::

::: {.slide .activity}
# Flash bibi — réinvestir l'hexadécimal

**Papier · seul · 8 min**

**À produire :** expliquer à côté de chaque réponse le passage par quartets.

1. `0111 1101 0000` → hexadécimal, puis **BI-DA-HO**.
2. `0011 1010` → hexadécimal, puis prononciation avec la table ci-dessus.
3. En une phrase : pourquoi le bibi-binaire n'est-il pas une nouvelle base ?

L'hexadécimal usuel `0–9, A–F` reste l'écriture de référence.
:::
