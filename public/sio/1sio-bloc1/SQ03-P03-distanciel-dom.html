1. Comprendre le DOM

Le problème

Vous avez écrit et modifié le code HTML de la page Soft-Tech. Mais quand un visiteur clique sur un bouton, comment le navigateur sait-il quel texte modifier ? Un fichier HTML n'est qu'une suite de caractères : le navigateur a besoin d'une représentation plus facile à parcourir.

Du fichier HTML à l'arbre

Voici une partie simplifiée de la page Soft-Tech :

<main>
  <h1>Soft-Tech</h1>
  <p id="conseil">Pensez à sauvegarder…</p>
  <ul>
    <li class="prestation">Diagnostic</li>
    <li class="prestation">Réparation</li>
    <li class="prestation">Entretien</li>
  </ul>
</main>

En lisant ce fichier, le navigateur construit un arbre : chaque élément devient un nœud, rangé sous son parent, avec ses attributs. Cet arbre s'appelle le DOM (Document Object Model).

  • main
    • h1 « Soft-Tech »
    • p id="conseil"
    • ul
      • li class="prestation" « Diagnostic »
      • li class="prestation" « Réparation »
      • li class="prestation" « Entretien »

L'indentation du code HTML reflète déjà cet arbre : un élément indenté sous un autre est son enfant.

Repérer un élément : id ou class

AttributIdéeSélecteur
id="conseil"Étiquette unique dans la page#conseil
class="prestation"Étiquette partagée par plusieurs éléments.prestation

Le # désigne un id, le . désigne une classe. Le CSS, que nous verrons bientôt, utilise exactement les mêmes sélecteurs.

Modifier un élément avec JavaScript

const conseil = document.querySelector("#conseil");
conseil.textContent = "Faites vos mises à jour.";
  1. querySelector cherche dans l'arbre le premier élément qui correspond au sélecteur.
  2. textContent remplace le texte de cet élément.
const bouton = document.querySelector("#bouton-conseil");
bouton.addEventListener("click", () => {
  conseil.classList.toggle("masque");
});

addEventListener attend un événement, ici un clic. À chaque clic, toggle ajoute la classe masque si elle est absente, et la retire si elle est présente. Une règle CSS déjà écrite cache les éléments qui ont cette classe.

À retenir

Le DOM est l'arbre que le navigateur construit à partir du HTML. Un sélecteur désigne un ou plusieurs éléments de cet arbre : # pour un id, . pour une classe. JavaScript peut attendre un clic et modifier un élément.
