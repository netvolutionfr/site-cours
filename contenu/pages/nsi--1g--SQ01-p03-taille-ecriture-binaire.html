Combien de bits ?

Taille d’une écriture binaire, somme, produit et dépassement

Objectifs

  • Déterminer le nombre de bits nécessaire pour écrire un entier, en l’encadrant entre deux puissances de 2.
  • Prévoir la taille d’une somme et d’un produit.
  • Expliquer un dépassement de capacité sur une taille fixe, et le simuler en Python.

Prérequis : poids des bits, divisions successives, tableau de suivi (partie 2).

Le problème

Taille d’un entier
Machine des nombres 8 bits : 255 au maximum
Python variable : 2 ** 100 s’affiche en entier
Processeur, fichier, réseau, capteur fixée à l’avance : 8, 16, 32 ou 64 bits

Deux questions pour un informaticien :

  1. Combien de bits un nombre demande-t-il ?
  2. Que se passe-t-il quand il n’y en a pas assez ?

Chaque bit double les possibilités

Bits Valeurs Plus grand entier Usage
1 2 1 vrai / faux
4 16 15 un chiffre hexadécimal
8 256 255 un octet, une couleur
16 65 536 65 535 numéro de port TCP
32 4 294 967 296 ≈ 4,3 milliards adresse IPv4
64 ≈ 1,8 × 10¹⁹ ≈ 1,8 × 10¹⁹ processeur actuel

Avec n bits : 2ⁿ valeurs, de 0 à 2ⁿ − 1. Repère : 2¹⁰ = 1024 ≈ 1000.

Combien de bits pour écrire N ?

N demande n bits quand 2ⁿ⁻¹ ≤ N < 2ⁿ : on encadre N entre deux puissances de 2 consécutives.

N Encadrement Bits Écriture binaire
13 8 ≤ 13 < 16 4 1101
200 128 ≤ 200 < 256 8 11001000
255 128 ≤ 255 < 256 8 11111111
256 256 ≤ 256 < 512 9 100000000

C’est la longueur de l’écriture binaire, sans zéros à gauche.

En Python

>>> bin(200)
'0b11001000'
>>> len(bin(200)) - 2
8
>>> (200).bit_length()
8
  • len(bin(n)) - 2 : longueur du texte, moins le préfixe 0b.
  • n.bit_length() : directement le nombre de bits.
  • Les parenthèses autour de 200 évitent que Python lise 200. comme un nombre à virgule.

Exercice 3.1 — Compter les divisions

Papier · seul puis à deux · 10 min

À produire : le tableau de suivi de nb_bits(13), puis les valeurs prévues pour 15 et 16.

def nb_bits(n):
    compteur = 1
    while n > 1:
        n = n // 2
        compteur = compteur + 1
    return compteur

Question à trancher à deux : pourquoi compteur commence-t-il à 1 ?

Le résultat d’un calcul

Somme et produit : raisonner sur le pire cas

Opération Plus grand résultat Taille
Somme de deux entiers de n bits 2ⁿ⁺¹ − 2 au plus n + 1 bits
Produit n bits × m bits (2ⁿ − 1)(2ᵐ − 1) < 2ⁿ⁺ᵐ au plus n + m bits
Sur 8 bits Calcul Bits nécessaires
Somme maximale 255 + 255 = 510 9
Produit maximal 255 × 255 = 65 025 16

Quand les bits manquent : le dépassement

Retenue 8 bits conservés
1 00000000

255 + 1 sur 8 bits : le 9e bit est perdu, le résultat vaut 0.

  • On parle de dépassement de capacité (overflow).
  • La machine compte « modulo 256 », comme un compteur kilométrique qui repasse à zéro.
  • En Python : (a + b) % 256 simule une addition sur 8 bits.

Des dépassements bien réels

Système Taille Conséquence
Pac-Man (1980) niveau sur 8 bits niveau 256 : moitié de l’écran illisible
Ariane 5, vol 501 (1996) entier de 16 bits calculateur arrêté, lanceur perdu
YouTube, Gangnam Style (2014) entier signé de 32 bits limite de vues proche : passage à 64 bits
Horloge Unix entier signé de 32 bits limite le 19 janvier 2038

Vérifier qu’un résultat tient dans sa taille : c’est de la mise au point.
