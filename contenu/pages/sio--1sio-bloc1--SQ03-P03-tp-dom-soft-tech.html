Objectifs

  • Repérer un élément HTML grâce à son id ou à sa class.
  • Lire et compléter un court programme JavaScript qui réagit à un clic.
  • Vérifier une modification dans le navigateur.

Prérequis

  • Structure d’une page HTML, balises et attributs.
  • Ouvrir un dossier dans VSCode, enregistrer et rafraîchir une page.

Sommaire

Étape Contenu
Étape 1 Observer l’arbre et les repères (10 min)
Étape 2 Modifier un texte avec JavaScript (10 min)
Étape 3 Réagir à un clic (15 min)
Étape 4 Défi : mettre une prestation en évidence (10 min)

Info

Cette activité est une découverte complémentaire de la séquence Web. Elle prépare la lecture des sélecteurs CSS, mais aucune compétence nouvelle n’est requise pour poursuivre le projet HTML Soft-Tech.

Consignes

En binôme, sur poste, 45 minutes environ. Travaillez sans IA ni recherche Internet : le but est de lire quelques lignes et de vérifier ce que le navigateur fait réellement.

Télécharger le projet dom-soft-tech (ZIP).

Extrayez le dossier dom-soft-tech dans votre espace de travail, ouvrez-le dans VSCode, puis ouvrez index.html dans un navigateur. Le fichier script.js est déjà relié à la page ; conservez les noms d’id et de class fournis.

La feuille de style incluse contient deux classes : masque cache un élément, selectionnee le met en évidence. Nous n’étudions pas encore le CSS : elles servent seulement à rendre le résultat visible.

Étape 1 - Observer les repères

10 minutes. Dans index.html, retrouvez le paragraphe qui porte l’attribut id=“conseil”, le bouton id=“bouton-conseil” et les trois éléments de classe prestation.

  1. Dans le navigateur, faites un clic droit sur le conseil puis choisissez Inspecter.
  2. Repérez l’élément HTML correspondant dans les outils de développement.
  3. Expliquez à votre binôme : pourquoi id=“conseil” est-il écrit une fois, alors que class=“prestation” apparaît trois fois ?

À produire : une phrase qui distingue le rôle d’un id et celui d’une class.

Étape 2 - Modifier un texte

10 minutes. Dans script.js, ajoutez après la ligne de commentaire :

const conseil = document.querySelector("#conseil");
conseil.textContent = "Un conseil : sauvegardez vos données avant toute réparation.";
  1. Enregistrez le fichier.
  2. Rafraîchissez la page.
  3. Vérifiez que seul le texte du conseil a changé.

À produire : le nouveau conseil, visible dans le navigateur.

Étape 3 - Masquer puis réafficher le conseil

15 minutes. Ajoutez ensuite le code suivant. Lisez-le avant de l’exécuter : que va faire la page au premier clic ? au second ?

const bouton = document.querySelector("#bouton-conseil");

bouton.addEventListener("click", () => {
  conseil.classList.toggle("masque");
});
  1. Enregistrez, rafraîchissez, puis cliquez deux fois sur le bouton.
  2. Décrivez ce que toggle(“masque”) fait à chaque clic.
  3. Modifiez le texte du bouton pour qu’il soit plus clair : « Afficher ou masquer le conseil ».

À produire : un bouton fonctionnel et une explication de l’alternance observée.

Étape 4 - Défi : mettre une prestation en évidence

10 minutes. Complétez ce code en remplaçant les deux points de suspension par les valeurs utiles.

const prestation = document.querySelector("...");
const boutonPrestation = document.querySelector("...");

boutonPrestation.addEventListener("click", () => {
  prestation.classList.toggle("selectionnee");
});

Le premier sélecteur doit retrouver la première prestation de la page. Le second doit retrouver le bouton prévu. Testez plusieurs clics.

À produire : le bouton « Mettre en avant une prestation » fait apparaître puis disparaître le cadre bleu autour de « Diagnostic ».

Vérification avant de terminer

Si un point manque, reprenez l’étape correspondante avant de montrer votre travail.
