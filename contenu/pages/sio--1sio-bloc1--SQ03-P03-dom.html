Le DOM : la page vue comme un arbre — cours

Retrouver un élément HTML pour le lire ou le faire évoluer

Avant le CSS : comprendre ce que les sélecteurs désignent.

Objectifs

  • Expliquer pourquoi le navigateur construit une représentation de la page.
  • Distinguer id et class pour repérer des éléments HTML.
  • Lire une modification simple déclenchée par un clic.

Prérequis : structure HTML, balises, attributs et indentation.

Le problème

Le code HTML de Soft-Tech décrit une page. Mais lorsqu’un utilisateur clique sur un bouton, comment le navigateur sait-il quel texte modifier ?

Il lui faut une représentation exploitable de la page, pas seulement une suite de caractères dans un fichier.

Du fichier HTML à l’arbre DOM

id ou class ?

Attribut Idée Pour le retrouver
id=“conseil” une étiquette unique dans la page #conseil
class=“prestation” une étiquette partagée par plusieurs éléments .prestation 
<p id="conseil">Pensez à sauvegarder vos données.</p>
<li class="prestation">Diagnostic</li>

Le CSS utilisera les mêmes sélecteurs : .prestation signifie « les éléments de la classe prestation ». Ici, nous les utilisons seulement pour les repérer.

Cibler, puis modifier un texte

const conseil = document.querySelector("#conseil");
conseil.textContent = "Pensez à sauvegarder vos données.";
  1. querySelector cherche le premier élément correspondant au sélecteur.
  2. textContent remplace son texte, sans interpréter ce texte comme du HTML.

On privilégie textContent : le programme modifie un texte, pas la structure de la page.

Réagir à un clic

const bouton = document.querySelector("#bouton-conseil");

bouton.addEventListener("click", () => {
  conseil.classList.toggle("masque");
});

addEventListener attend un événement. Au clic, le programme ajoute ou retire la classe masque. La règle CSS qui cache l’élément est fournie : nous observons le lien avec une classe, sans apprendre encore à écrire du CSS.

À vous : rendre la page interactive

35 min - en binôme, sur poste

À produire : une page Soft-Tech où un bouton masque ou réaffiche un conseil, puis met en évidence une prestation.

Suivez la fiche d’activité. À chaque étape : prévoir, modifier, enregistrer, rafraîchir et observer.

Ce que nous retenons

  1. Le DOM est l’arbre que le navigateur construit à partir du HTML.
  2. Un sélecteur désigne un élément dans cet arbre : # pour un id, . pour une classe.
  3. JavaScript peut attendre un clic et modifier l’état d’un élément.
