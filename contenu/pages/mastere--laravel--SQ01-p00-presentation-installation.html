Créer le projet

composer global require laravel/installer
laravel new voyages-scolaires
cd voyages-scolaires
php artisan serve

Ouvrir http://127.0.0.1:8000 : la page d’accueil de Laravel.

Par défaut, la base est un fichier SQLite créé et migré à l’installation.

Où est quoi ?

Dossier ou fichier Contenu
routes/web.php Les URL de l’application
app/Http/Controllers/ Les contrôleurs
app/Models/ Les modèles Eloquent
resources/views/ Les vues Blade
database/migrations/ L’historique du schéma de la base
.env La configuration de ce poste

Le fichier .env

APP_NAME="Voyages scolaires"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://127.0.0.1:8000

DB_CONNECTION=sqlite
  • Une configuration par environnement : poste, test, production
  • Jamais commité : il contient des secrets (APP_KEY, mots de passe)
  • APP_DEBUG=true en production affiche le code et la configuration à tous

Artisan, la ligne de commande du projet

php artisan list                 # toutes les commandes
php artisan route:list           # les routes déclarées
php artisan make:controller ...  # générer un contrôleur
php artisan make:model ... -m    # un modèle et sa migration
php artisan migrate              # appliquer les migrations
php artisan tinker               # du PHP dans l'application

Toujours à la racine du projet, là où se trouve le fichier artisan.

Une première route

// routes/web.php
use Illuminate\Support\Facades\Route;

Route::get('/', function () {
    return view('welcome');
});

Route::get('/bonjour', fn () => 'Bonjour Laravel !');

Une route associe une méthode HTTP et une URL à une action.

À vous

Seul · sur son poste

À produire : le projet qui démarre et une route /bonjour qui répond.

  1. Créer le projet, le lancer, ouvrir la page d’accueil
  2. Ajouter la route /bonjour, la vérifier avec php artisan route:list
  3. Retrouver dans le projet le fichier de la page d’accueil

À retenir

  • Laravel structure le projet : routes, contrôleurs, modèles, vues, migrations
  • .env configure un poste et ne se commite pas
  • php artisan génère le code et administre le projet
  • Une route relie une URL à une action
