Dans le coffre-fort Python du 2 octobre, la fonction tarif(age) devait donner un prix. Mais comment faire si un autre calcul a besoin de ce prix ? Une valeur affichée à l’écran ne suffit pas : le programme doit pouvoir la récupérer.

Objectifs

  • Distinguer ce qui s’affiche de la valeur renvoyée par une fonction.
  • Écrire une fonction de calcul avec return, puis utiliser son résultat ailleurs.
  • Décrire simplement les valeurs qu’une fonction accepte et celles qu’elle renvoie.

Prérequis

  • Savoir définir et appeler une fonction simple avec def.
  • Savoir affecter une valeur à une variable.
  • Un crayon suffit pour la version papier ; la page HTML interactive demande une connexion Internet au premier chargement de Python.

Info


En mathématiques, une fonction prend une valeur dans un
ensemble de départ et donne une valeur dans un
ensemble d’arrivée. Ici, la valeur de départ est un
couple de nombres entiers (prix_unitaire et
quantite) ; la fonction renvoie un nombre entier (un prix
en euros). En Python, on peut dire :
prix_billets : (int, int) → int. Cette écriture décrit les
types des valeurs attendues et du résultat ; elle ne
remplace pas le calcul.

1. Même nombre à
l’écran, résultat différent


double_affiche(4) affiche 8, mais ne
renvoie pas de résultat utile : a vaut None.
double(4) renvoie 8, sans rien afficher au
moment de son appel : b vaut 8. Les lignes
visibles sont, dans l’ordre :


8
a = None
b = 8


b + 3 vaut 11. a + 3 produit
une erreur, car None n’est pas un nombre. Le deuxième test
obtient donc None au lieu de 8. Après avoir
remplacé print par return dans
double_affiche, a vaut 8 lors
d’une nouvelle exécution.


2. Réparer la billetterie


La première version affiche 21, mais
sous_total vaut None : l’addition avec
2 échoue. Il faut renvoyer le résultat :


def prix_billets(prix_unitaire, quantite):
    return prix_unitaire * quantite


Les appels renvoient respectivement 21, 10
et 0. La dernière ligne affiche
Total : 23 €.


3. Une fonction peut
en appeler une autre


def prix_pour_deux(age1, age2):
    return tarif(age1) + tarif(age2)

print("Prix :", prix_pour_deux(10, 70), "€")


Les deux paramètres sont de type int (des âges entiers)
; le résultat est de type int (un prix entier). Afficher le
prix peut convenir si l’on veut seulement le montrer à l’écran. Mais si
une autre fonction doit ajouter des frais, comparer deux prix ou
calculer une réduction, il lui faut la valeur
renvoyée.
