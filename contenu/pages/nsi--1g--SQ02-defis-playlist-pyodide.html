Une application de musique range vos morceaux dans des listes, calcule des durées et vous recommande le morceau suivant. Programmez ces fonctions une par une, jusqu’à la recommandation.

Objectifs

  • Parcourir une liste pour compter, chercher ou totaliser.
  • Construire une nouvelle liste sans modifier l’ancienne.
  • Renvoyer un tuple et parcourir une liste de tuples.

Prérequis

  • Variables, if, for, range, fonctions et return.
  • Une liste, ses indices et len (SQ02, P01).
  • Un téléphone ou un ordinateur avec Internet : rien à installer.

Écrivez plus_long(durees) qui renvoie

def nb_titres(playlist):

Indice : on peut renvoyer True dès qu’on trouve le

def contient(playlist, titre):
    for t in playlist:
        if t == titre:
            return True
    return False


Défi 4


Indice : un accumulateur initialisé à 0 avant la boucle.


def duree_totale(durees):
    total = 0
    for d in durees:
        total = total + d
    return total


Défi 5


Indice : comparer durees[i] avec
durees[i_max], strictement, pour garder le premier en cas
d’égalité.


def plus_long(durees):
    i_max = 0
    for i in range(len(durees)):
        if durees[i] > durees[i_max]:
            i_max = i
    return i_max


Défi 6


def courts(durees, limite):
    resultat = []
    for d in durees:
        if d <= limite:
            resultat.append(d)
    return resultat


Défi 7


Indice : [titre] + resultat place le titre devant.
resultat + [titre] recopierait la liste dans le même
ordre.


def inverser(playlist):
    resultat = []
    for titre in playlist:
        resultat = [titre] + resultat
    return resultat

Défi 10


Indice : comme pour le meilleur score, on garde la plus
petite distance vue jusqu’ici et le titre qui va
avec.


def recommander(morceaux, tempo, energie):
    titre_proche = morceaux[0][0]
    d_min = distance(tempo, energie, morceaux[0][1], morceaux[0][2])
    for morceau in morceaux:
        titre, t, e = morceau
        d = distance(tempo, energie, t, e)
        if d < d_min:
            d_min = d
            titre_proche = titre
    return titre_proche
