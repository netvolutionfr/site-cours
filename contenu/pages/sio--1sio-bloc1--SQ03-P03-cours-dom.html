Votre mission

Soft-Tech veut un bouton qui masque puis réaffiche son conseil pratique. Vous allez le réaliser et expliquer son fonctionnement. Le CSS est fourni ; vous n’avez pas à l’écrire aujourd’hui.

Travaillez en binôme sur un poste, dès la classe entière. L’un manipule, l’autre lit les consignes et vérifie ; échangez les rôles après la modification du texte. Sans IA ni recherche Internet : les ressources nécessaires sont ici. L’activité à distance du 1er octobre n’est pas un prérequis.

Commencer — classe entière

  1. Téléchargez le dossier Soft-Tech, extrayez-le dans votre espace de travail et ouvrez le dossier dans VSCode. Ouvrez index.html dans le navigateur. Gardez index.html et script.js côte à côte.
  2. Ouvrez la fiche d’activité en ligne. Faites l’étape 1 : inspectez le conseil et retrouvez ses repères dans le HTML. Chacun écrit une phrase distinguant id et class.
  3. Faites l’étape 2 : prévoyez quel texte changera, puis modifiez le script, enregistrez, rafraîchissez et comparez votre observation à votre prévision.
  4. Avant l’étape 3, chacun prévoit l’état du conseil après le premier et le deuxième clic. Confrontez vos prévisions puis testez le bouton si le temps le permet.

À montrer : le conseil modifié et, si vous avez atteint l’étape 3, le bouton fonctionnel. À expliquer : quel élément est ciblé et pourquoi les autres textes ne changent pas.

Aide — le texte ne change pas

Vérifiez le fichier enregistré, le dossier de la page ouverte et le rafraîchissement. Comparez ensuite le nom après # avec l’attribut id du paragraphe. Si l’erreur persiste, regardez la console du navigateur avec votre enseignant.

Clore la classe entière — dix dernières minutes

Arrêtez les modifications à la demande de l’enseignant. Deux binômes montrent leur résultat ; les autres comparent aux prévisions. Chacun conserve dans ses notes :

  • « Le navigateur construit le DOM à partir de… »
  • « Pour retrouver le conseil, le programme utilise… »
  • « Avant le clic…, au premier clic…, au deuxième clic… »

Enregistrez vos fichiers pour les reprendre en demi-groupe.

Reprendre — demi-groupe

Repartez de vos fichiers, sans recommencer les étapes réussies. Terminez l’étape 3, changez le libellé du bouton et vérifiez deux clics successifs. Si cela fonctionne et que chacun sait l’expliquer, essayez le défi de l’étape 4. Le second bouton est facultatif : il n’est pas nécessaire pour valider l’objectif commun.

Pour les dix dernières minutes, préparez une démonstration et une explication par chacun des deux partenaires. Gardez une trace individuelle du cycle prévoir → enregistrer → rafraîchir → observer.

Le cours — à relire après avoir cherché

Le fichier HTML décrit la page. Le navigateur en construit une représentation en forme d’arbre : le DOM. JavaScript peut retrouver un élément de cet arbre et modifier ce que la page affiche.

Repère dans le HTML Sélecteur Ce qu’il désigne
id="conseil" #conseil Le repère unique du conseil
class="prestation" .prestation Une classe partagée par plusieurs prestations

querySelector renvoie le premier élément qui correspond au sélecteur. Ainsi, une classe peut être partagée, mais querySelector(".prestation") ne renvoie pas toutes les prestations.

const conseil = document.querySelector("#conseil");
conseil.textContent = "Un conseil : sauvegardez vos données avant toute réparation.";

La première ligne retrouve le conseil. La deuxième remplace son texte, sans interpréter ce texte comme du HTML.

const bouton = document.querySelector("#bouton-conseil");
bouton.addEventListener("click", () => {
  conseil.classList.toggle("masque");
});

Le programme attend un événement, ici un clic. toggle("masque") ajoute la classe si elle est absente et la retire si elle est présente. Dans le CSS fourni, cette classe cache l’élément : le conseil visible au départ est donc masqué au premier clic, puis réaffiché au deuxième.
