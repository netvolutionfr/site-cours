Lundi, la fonction lire_octet de la machine des nombres a résisté. Ce n’est pas un hasard : elle demande trois idées nouvelles en même temps. Une boucle qui fait évoluer deux variables, une boucle for qui parcourt les caractères d’un texte, et un if à l’intérieur de la boucle. Aujourd’hui, on apprend ces idées une par une, puis on revient à la machine.

Objectifs

  • Suivre, tour par tour, les valeurs d’une variable modifiée dans une boucle.
  • Initialiser avant la boucle et modifier dans la boucle un accumulateur ou un compteur.
  • Parcourir une chaîne caractère par caractère avec for c in texte.
  • Placer un if dans une boucle, puis écrire lire_octet seul.

Prérequis

  • Boucle for avec range, conditions if, fonctions avec return.
  • Poids des bits d’un octet : 128, 64, 32, 16, 8, 4, 2, 1.
  • Un téléphone ou un ordinateur avec Internet : rien à installer. Une feuille et un crayon.

Indice : c’est exactement B1, avec total à la place

def grains(cases):
    total = 0
    sur_la_case = 1
    for i in range(cases):
        total = total + sur_la_case
        sur_la_case = sur_la_case * 2
    return total

    return nb

def lire_octet(bits):
    total = 0
    poids = 128
    for bit in bits:
        if bit == "1":
            total = total + poids
        poids = poids // 2
    return total


11111111 additionne tous les poids :
128 + 64 + … + 1. L’échiquier additionne les mêmes nombres,
de 1 à 128, sur huit cases : les deux valent 255, soit
2⁸ − 1.
